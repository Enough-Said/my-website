# My Website

This is my website, built using Tanstack Start with typescript, react, and tailwind-css. 

Currently has two public pages:
- Home
- Projects

Also has one admin page:
- admin/projects

---
## Public Pages
There is a projects page which includes descriptions of my projects and links to them. 

## Admin Pages
Admin pages are only available from the development version of the website. This way, only the computer hosting the website should be able to access those webpages and also the database. 

There is an admin page for adding and removing projects from the database.
